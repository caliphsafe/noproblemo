# No Problemo — Organized Chalk Refinement

This build intentionally restores the organized pre-chalk layout and keeps only the improved mobile navigation behavior.

## Visual direction
- Original structured desktop layout restored.
- Boxes/tickets/panels remain aligned and rectangular.
- Digital-perfect 1px rules are replaced with restrained distressed chalk assets.
- Chalk borders are visually about 2–3px, not oversized frames.
- Item dividers use a thin distressed chalk stroke and never overlap item text.
- No background dots.

## Mobile
- Horizontal swipeable category rail retained.
- Tap category or swipe the menu to move between categories.
- Previous/next category arrows retained.
- Single-column ledger and compact mobile checkout retained.

No Supabase migration is required for this visual/mobile refinement.
